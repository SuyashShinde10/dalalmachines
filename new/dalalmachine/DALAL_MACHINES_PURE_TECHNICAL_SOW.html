1.0 Project Overview & Engineering Objectives

This Technical Statement of Work (SOW) defines the complete functional, architectural, and deployment deliverables for the fullstack digital transformation of Dalal Machine Tools Agency Pvt. Ltd. With over two decades of recognized standing in industrial machinery import, stocking, and supply, the organization requires an enterprise-class digital platform to showcase its multi-thousand-ton metal forming and cutting inventory to domestic and international industrial buyers.

The scope encompasses the end-to-end realization of a unified corporate platform consisting of five tightly integrated subsystems:

  1. Client-Facing B2B Machinery Portal: A fully responsive 24-page web interface housing the 26-category machine inventory, standardized technical specification matrices, and interactive lead acquisition funnels.
  2. Import Duty & High Seas Savings Calculator: An interactive computational engine calculating customs tariff optimization and GST Input Tax Credit (ITC) eligibility.
  3. Staff Operations Portal (/admin): A dedicated operations hub enabling staff to manage machine listings, update live/sold states, review inquiries, and export catalog data without developer intervention.
  4. Super-Admin Governance Console (/superadmin): A restricted management console providing system telemetry, role-based access control (RBAC), immutable security audit logs, and automated database snapshot backup/restore.
  5. Discoverability & Infrastructure Layer: Comprehensive technical SEO, JSON-LD Schema markup, Generative AI Engine Optimization (AEO), Google Search Console domain verification, GA4 conversion tracking, SSL certificate security, and production daemon configuration.
Core Engineering Philosophy
Zero third-party vendor lock-in. The platform is constructed entirely using clean, semantic web architecture (Semantic HTML5, CSS3, Vanilla JS, Node.js runtime, standard JSON schemas) ensuring high performance, zero runtime license fees, and complete intellectual property ownership for Dalal Machine Tools Agency Pvt. Ltd.

3.4 1-Click WhatsApp Direct RFQ Lead Engine

To eliminate customer friction and bridge web inquiries directly to sales executives, every machine card and PDP includes an automated WhatsApp RFQ generator. Clicking the button executes a client-side URL builder:

  • Reads the active machine Title, Tonnage, Model, and URL.
  • Formats an encoded string: "Hello Dalal Machines, I am interested in [Machine Title] (Ref: [ID]) currently listed on your portal. Please share full technical specifications, inspection report, and quotation details."
  • Directly triggers the WhatsApp application on mobile or WhatsApp Web on desktop without requiring manual typing.

3.5 High Seas Sales & Import Finance Calculator

An interactive computational tool located on the Services page allowing industrial clients to estimate their procurement savings when purchasing high-value capital goods under High Seas Sales agreements:

  • Inputs: Machine Baseline CIF Capital Valuation, applicable Customs Duty tariff rate, Port Clearance charges, and standard inland logistics.
  • Computational Engine: Evaluates total landed expense under standard direct import versus High Seas Sales transfer prior to customs clearance.
  • Output Display: Clear graphical summary demonstrating total cash outflow reduction, duty deferral benefits, and full 100% eligibility for GST Input Tax Credit (ITC).

4.0 Technical SEO, Generative AEO & Webmaster Integration

Search engine optimization is embedded directly into the platform architecture to establish dominant organic search rankings for high-intent B2B machinery keywords:

  • On-Page Technical SEO: Unique Meta Titles, keyword-dense Meta Descriptions, OpenGraph social sharing cards, and Canonical URL tags configured across all 24 individual pages.
  • Automated Dynamic XML Sitemap & Robots.txt: Automatically generated sitemap.xml with strict crawl priority tags and robots.txt directing Googlebot to all catalog categories.
  • Structured Rich Schema Markup (JSON-LD):
    • Organization Schema: Official legal identity, registered office address, and contact endpoints.
    • LocalBusiness Schema: Dual geocoded coordinates covering both the Tardeo Mumbai Headquarters and Chakan Stock Yard.
    • Product & ItemList Schema: Formatted per Google Search Central standards to trigger rich snippet stars, inventory availability, and technical spec previews in search results.
  • Generative AI Engine Optimization (AEO): Semantic content hierarchy structured to facilitate direct entity indexing and factual citations by conversational AI models (ChatGPT, Perplexity AI, Google AI Overviews, Gemini).
  • Google Search Console DNS Verification: Verification via DNS TXT records and submission of XML sitemaps for rapid indexing.
  • Google Analytics 4 (GA4) Telemetry: Property configuration with custom event tracking for WhatsApp clicks, phone call taps, and RFQ form completions.

5.0 Production Hosting, Server Architecture & Security Hardening

The production deployment architecture is engineered for 99.9% uptime, zero memory leaks, and enterprise-grade resilience:

Component Configuration & Implementation Detail Operational Benefit
Process Management PM2 Process Manager operating under Node.js runtime with automatic cluster restart on failure and log rotation. Zero downtime; automatic self-healing daemon.
Domain DNS Mapping Root domain A-Records, CNAME records, and automated 301 redirection from www to non-www canonical URL. Eliminates duplicate content penalties; seamless web access.
SSL / TLS Security Automated Let's Encrypt SSL certificate with TLS 1.3 encryption and automated 90-day renewal protocols. End-to-end data encryption and green padlock browser trust.
Rate Limiting Protection IP-based sliding window rate limiter: max 25 req/min on administrative login routes; max 30 req/min on public RFQ endpoints. Prevents brute-force credential stuffing and spam bot abuse.
XSS & Injection Defense Strict input sanitization escaping HTML entities on all form submissions; parameterized database writes. Eliminates stored cross-site scripting (XSS) risks.
Security Headers Helmet-compliant HTTP response headers: X-Content-Type-Options: nosniff, X-Frame-Options: SAMEORIGIN, Referrer-Policy. Hardened protection against clickjacking and MIME sniffing.
Regression Testing 24/24 automated test runner verifying routing, layout rendering, search query parsing, and API responses prior to deployment. Guarantees zero regression bugs upon live production release.
