On-Premise LAN Infrastructure & Minimum Host PC Specifications

To eliminate recurring cloud SaaS licensing (saving ₹1.5L–₹3.0L annually), the OMPI Central ERP deploys on a dedicated Host PC within the Pune office. All staff access the software via standard web browsers across the local Wi-Fi/Ethernet network:

Hardware & Network Requirements Client Domain
  • Host PC/Server: Intel Core i5/i7 (8th Gen+) or AMD Ryzen 5+, 16 GB RAM minimum, 512 GB NVMe SSD.
  • Power Supply & UPS: Dedicated UPS with minimum 30-minute battery backup to prevent database write corruption during load shedding.
  • Local Network: Standard Gigabit Ethernet switch or Wi-Fi 6 router connecting staff laptops and desktops.
Defined 3-Tier Backup Architecture Disaster Recovery
  • Tier 1 (Host Snapshot): Daily automated SQLite database snapshot archived to a secondary directory on Host PC.
  • Tier 2 (Physical Drive Mirror): Weekly scheduled mirror copy synchronized to an external USB SSD/HDD.
  • Tier 3 (Off-Site Encrypted Cloud): Periodic encrypted backup stored in Client's secure corporate Google Drive or OneDrive.
* Host Environment Boundaries: Physical machine maintenance, uninterrupted electrical power supply, operating system licensing/updates, commercial antivirus protection, and internal staff password hygiene remain the exclusive operational responsibility of the Client.
