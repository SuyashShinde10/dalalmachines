On-Premise LAN Infrastructure & Minimum Host PC Specifications

To eliminate recurring third-party cloud SaaS user subscriptions (saving ₹2,50,000+ annually), the OMPI Central ERP deploys on a dedicated Host PC within the Pune office. All staff access the software via standard web browsers across the local Wi-Fi/Ethernet network:

Hardware, Power & Concurrency Client Domain
  • Host PC/Server: Intel Core i5/i7 (8th Gen+) or AMD Ryzen 5+, 16 GB RAM minimum, 512 GB NVMe SSD.
  • Power Supply & UPS: Dedicated UPS with minimum 30-minute battery backup to prevent database write corruption during power outages.
  • Local Network: Standard Gigabit Ethernet switch or Wi-Fi 6 router connecting staff laptops and desktops.
  • Concurrency Baseline: ACID SQLite architecture is optimized for up to 15–20 concurrent office LAN users. (Scaling beyond 20 concurrent write-heavy users requires migration to PostgreSQL, quotable under a future CR).
Defined 3-Tier Backup Architecture Disaster Recovery
  • Tier 1 (Host Snapshot): Daily automated SQLite database snapshot archived to a secondary directory on Host PC.
  • Tier 2 (Physical Drive Mirror): Daily synchronized mirror copy to an external physical USB SSD/HDD (Client ensures external drive remains connected and mounted).
  • Tier 3 (Off-Site Encrypted Cloud): Periodic encrypted backup stored in Client's secure corporate Google Drive or OneDrive.
  • Operational Backup SLAs: Automated scripts are provided; Client is responsible for keeping external drive connected and cloud credentials valid. Recovery Time (RTO) guarantees are disclaimed due to reliance on client-managed hardware.
* Host Environment Boundaries: Physical computer maintenance, continuous electrical power, operating system licensing/updates, commercial antivirus protection, and internal staff password hygiene remain the exclusive operational responsibility of the Client.
