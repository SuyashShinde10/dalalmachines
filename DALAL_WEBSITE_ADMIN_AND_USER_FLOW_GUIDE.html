1.2 Standard 10-Parameter Engineering Machinery Grid

Har machine detail page aur admin entry form par standardized 10 engineering parameters implement kiye gaye hain:

  • 1. Machine Model & Make: Manufacturer, origin (Germany/Japan/Russia), year.
  • 2. Rated Tonnage Capacity: Metric Tons pressing force (e.g. 400T, 1600T, 4000T).
  • 3. Stroke Length & Adjustment: Slide travel distance (mm) & motorized adjust.
  • 4. Continuous Speed (SPM): Strokes per minute under continuous/single cycling.
  • 5. Bed & Bolster Dimensions: Left-to-Right × Front-to-Back platen area.
  • 6. Die Shut Height (SDAU): Bed-to-slide distance for tooling fitment verification.
  • 7. Clutch & Brake Mechanism: Pneumatic friction/hydraulic unit (OMPI compatible).
  • 8. Main Drive Motor Power: Motor power rating in kW / HP and flywheel RPM.
  • 9. Gross Physical Weight: Total assembled weight in Metric Tons (approx. MT).
  • 10. Physical Yard Location: Chakan Central Yard (Pune) / European Stock.

4.0 Master Super-Admin Governance Console

Super-Admin Console company ke Managing Director aur Principal Software Engineer ka isolated, high-security governance console hai. Ye portal ordinary internet users ya staff ke liye completely invisible (cloaked 404) rehta hai:

SecOps Architecture & Multi-Layer Intrusion Defense

Koi bhi scanner ya unauthorized user agar /superadmin ya /admin access karne ki koshish karega, system standard login page dikhane ke bajaye 404 Not Found return karta hai. Authorized access ke liye:

1. Cloaked Gateway Key
Requires pre-configured HMAC gateway key to unlock login route.
2. Honeypot Traps
Fake paths (/wp-admin) catch malicious bot scans and log IP.
3. Signed Session Cookies
HTTP-only, SameSite strict session tokens prevent CSRF/XSS.

4.1 Super-Admin Functional Modules

1. Executive Telemetry (dashboard.html) Telemetry
  • Real-time Uptime Monitor: Node.js server status, memory footprint, active HTTP connections.
  • Total Audited Machinery Count: Verification that catalog matches physical yard audit.
  • Aggregated RFQ Lead Volume: Total inquiry tally with conversion win/loss percentages.
  • Live System Health Alert: Visual green badge confirming sub-10ms micro-cache status.

Kaam: Director ko ek single screen par company ke technical aur commercial traffic ki health dikhana.

2. Staff Accounts & RBAC (users.html) Access Control
  • User Account Creation: Create staff accounts with distinct usernames and email IDs.
  • Role Segregation (RBAC): Assign "Operations Staff", "Sales Agent", or "Super Admin" permissions.
  • Instant Lockout Override: 1-Click disable toggle to instantly revoke staff access if someone leaves.
  • Password Reset Engine: Secure password hash generation using Bcrypt with 10 salt rounds.

Kaam: Staff permissions control karna taaki unauthorized staff critical database delete na kar sake.

3. Security Audit Ledger (logs.html) Compliance
  • Immutable Action Logging: Every product add, price change, lead deletion is logged with timestamp, user ID, and IP address.
  • Intrusion Attempt Alerts: Failed password attempts, honeypot hits, rate-limit triggers.
  • Exportable Security Trail: Download security logs for IT audit and compliance.

Kaam: Complete transparency; agar koi machine galti se delete ho, toh pata chalta hai kisne kiya.

4. Database Backup & Restore (settings.html) Disaster Recovery
  • 1-Click JSON Database Export: Downloads entire system database (products, specs, leads, users) in one click.
  • Database Restore Engine: Upload JSON backup to restore entire catalog in case of server failure.
  • Cache & Sitemap Rebuild: 1-Click button to force-refresh dynamic 83-URL XML sitemaps and /llms.txt.

Kaam: 100% data safety; server crash hone par 60 seconds me pura business restore ho jata hai.
